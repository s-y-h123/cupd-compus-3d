# 中石大场景后续迭代清单

以下是后续可选工作，均不属于当前场景接入已交付的功能。推进前先补齐对应数据或分层资产，并保持现有 UI 与相机交互风格。

| 功能 | 所需输入 | 验收要点 |
| --- | --- | --- |
| 距离测距 | 与模型同坐标的米制比例、可拾取地面或路径 | 两点测量结果与已知长度对照；显示水平距离或空间距离的明确单位。 |
| 地标信息弹窗 | 经核实的建筑名称、用途、图片和来源 | 点击标签后内容对应正确建筑，移动端可阅读，资料时间与来源可查。 |
| 路线导航 | 可通行步道网络、道路交叉点、出入口、禁行区域 | 路线不穿越建筑或水体，支持起终点选择和不同校区间的实际过街连接。 |
| 分层模型 | 同原点的建筑、道路、植被、水体等独立节点或 GLB | 原版图层开关分别控制对应类别；近景和整体视角都无错位。 |
| 复杂地形碰撞升级 | 新模型的独立地形碰撞层、坡度与禁行区域 | 在山地/台阶/水岸模型上复核地面高度和可通行性；当前第一视角已提供建筑足迹与覆盖范围碰撞。 |

优先补齐模型的坐标基准、分层结构和地标实测点位，再开发测距与导航。这些基础数据也决定后续功能能否给出可信结果。
